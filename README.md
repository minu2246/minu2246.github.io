# 김민우 | Minwoo Kim

건양대학교 의료IT공학과에서 의료IT와 인공지능을 공부하며, 실제로 사용할 수 있는 헬스케어 서비스를 개발하고 있습니다.

- 관심 분야: 헬스케어 AI, 의료 데이터, 컴퓨터 비전, 음성 인식(STT), 모바일 앱 개발
- GitHub: [@minu2246](https://github.com/minu2246)
- 포트폴리오 웹사이트: [minu2246.github.io](https://minu2246.github.io)

## 주요 프로젝트

### MedMap — 의료 정보 정리 및 진단 안전망
환자의 증상과 시간에 따른 변화를 구조화해 진료 전 정보를 정리하고, 환자 상태와 기존 판단 사이에 중요한 불일치가 있는지 확인하도록 돕는 프로젝트입니다. 의료진의 진단을 대체하는 것을 목표로 하지 않습니다.

- 기술: Python, FastAPI, React, TypeScript, Vite, Capacitor, Whisper 기반 음성 인식
- 저장소: [minu2246/MedMap](https://github.com/minu2246/MedMap)

### 이웃냉장고 — 지역 기반 식재료 나눔 앱
남는 식재료를 가까운 이웃과 나누거나 교환할 수 있도록 연결하는 위치 기반 서비스입니다.

- 기술: Expo / React Native, TypeScript, NestJS, PostgreSQL, PostGIS, Docker
- 핵심 기능: 주변 게시물 검색, 소비기한 관리, 채팅, 거래 약속, 포장지 OCR

### MelanoScan — 피부 병변 분석 및 추적 앱
피부 병변 이미지를 분류하고, 병변 크기와 측정 기록을 추적하도록 돕는 Android 앱입니다. 결과는 참고 정보이며 의료진의 진단을 대체하지 않습니다.

- 기술: Kotlin, Android Studio, TensorFlow Lite, EfficientNetV2-S, Room
- 저장소: [minu2246/MelanoScan](https://github.com/minu2246/MelanoScan)
